# AGENTS

This folder holds repo-local skills and agent-facing guidance.

- Keep skills concise and procedural.
- Put detailed rationale or research into `references/` files instead of bloating `SKILL.md`.
- If a skill governs a recurring workflow in this repo, root `AGENTS.md` should point to it explicitly.
- When the workflow changes, update the skill in the same change.
- `spm-self-hosting/` is the skill for using Spec Embryo recursively on this repo itself.
- `spec-writer/` and `spec-reviewer/` govern the required spec authoring loop for substantive specs in this repo.
