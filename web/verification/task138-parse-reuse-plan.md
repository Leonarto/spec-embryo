# TASK-138 — exact-byte validated parse-reuse experiment

Astra High technical decision; copy-only authorization.


Astra selects one COPY-ONLY measured candidate, not a production implementation: bounded reuse of successful parsed canonical documents after a NEW full read proves the bytes exactly equal. The measured TOML (~60ms) and domain (~5ms) CPU spans justify investigating avoided parsing; no promise that clone/lookup overhead will recover enough latency. Do not sweep concurrency, revive workers, change the TOML parser, skip collections, alter runtime or introduce dependencies.

Prototype contract:
- Every load freshly enumerates and reads all enabled documents as today, including current/session/org where enabled; configuration and Git remain fresh. No stat/mtime/TTL shortcut, watcher, cached context, DTO cache, pending-promise sharing or negative/error cache.
- Private bounded memo key includes the exact resolved document path and parser identity. A hit additionally requires byte-for-byte equality of the complete NEW Buffer against the retained successful bytes, not only a hash. Different parser identity, bytes, missing/deleted path or failure uses the existing normal path. Function wrappers whose identity changes may simply miss; do not infer equivalence of parsers/scopes.
- Cache only successful canonical document values. Keep the retained value private and return a fresh independent clone on EVERY publication, including misses. Run existing provenance registration using the newly read Buffer and the fresh returned object; never copy WeakMap provenance from an old object or claim parsing ran again on a hit. This is an explicit experimental change from reparsing each read to exact-byte CPU reuse, not a relaxation of fresh source observation. Unsupported/noncanonical values may bypass the prototype memo rather than gain custom serialization semantics.
- Fixed cap16384entries and32MiB accounted retained raw-byte length plus UTF8 serialized canonical-value length; oversized individual entries bypass, evict oldest/LRU under the fixed cap. This is a deterministic accounting budget, not an asserted JS heap measurement. No mutable object sharing with consumers, no public configuration or cache API. Include clone, byte comparison, accounting and eviction costs in timing; collect retained entry/accounted-byte counts. Do not retain superseded versions for the same key.
- First prove full canonical context, source revision and Task/Spec DTO equality against the existing loader with fixed clock inputs, plus freshness on same-length edits with restoredmtime, atomic replacement, addition/deletion, parse failure/recovery and mutation of a previously returned document. Revisions must still hash the actual new source Buffer. Include enabled scoped-note correctness; no performance claim from unexercised note paths.
- Then one quiet3warm+5serial matched AB/BA experiment on the exact same Node/fixture, measuring context wall and clone/parse/lookup cost. Cache is empty at candidate process start; warmup fills it naturally. Record baseline and candidate raw values, source hashes, membership/bytes and memory accounting. If improvement is not clear, stop and report; no unapproved variant chain.

Only a promising result may proceed to matched5+20 confirmation and a concrete independently reviewed production design. The experiment itself does not authorize shipping a cache, editing shared repository source, revising production provenance claims, marking138done or claiming300ms. Final e2e acceptance must use the eventual exact reviewed combined product.
