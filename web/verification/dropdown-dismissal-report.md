# Serialized dropdown dismissal checkpoint

Only SelectDropdown, MultiSelectDropdown and Popover change. Dropdown outside dismissal now uses bubbling `click`, so the clicked control acts before inline content collapses. Escape listeners attach to each native details node through a local action with cleanup: the child closes/focuses its summary and marks defaultPrevented, then a second Escape reaches the parent. No stopPropagation, artificial role, FormData, markup hierarchy or Popover outside-pointerdown change.

[Red evidence](dropdown-dismissal-red.json) reproduces the lost first Apply click in the already committed Tasks route, with valid intended FormData; it also records the parent-first Escape failure. Gesture input targets the visible portion of the clipped option-list; aiming below its parent's clipping edge initially scrolled a different container and was corrected in the test harness.
