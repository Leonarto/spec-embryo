# AGENTS

Local SvelteKit workspace for Spec Embryo.

- Shared deterministic root services supply data; keep route loads thin and do not re-parse documents here.
- Spec question answers are the sole supported UI mutation, through the canonical action and shared service.
- Preserve the compact editorial operations direction: solid semantic tokens in `src/app.css`, focused routes, and consistent Lucide icons.
- `spm ui` must work from dev and globally installed npm source under `node_modules`; preserve packaged Vite paths and assets.
- `scripts/workspace-benchmark.ts` creates disposable volume fixtures; `verification/` records measurements and browser evidence.
- `.svelte-kit/` is generated by sync/dev/build and must never be versioned or included as source in a package.
